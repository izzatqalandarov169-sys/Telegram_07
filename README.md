# Telegram_07 — UI-only client

This project is intentionally **UI-only**. It does not contain Telegram MTProto networking, Telegram API endpoints, API ID/hash, or Telegram account authentication.

The visual direction follows the Telegram Android client style. Telegram's Android application source is published under GPL v2-or-later; this project will keep third-party license notices with any source that is actually reused. Telegram also asks developers using its source to use their own `api_id`, avoid calling an unofficial app Telegram, avoid its standard logo, and publish source as required by the license.

Source/reference: https://github.com/DrKLO/Telegram
